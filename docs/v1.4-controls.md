# Niagara Drift v1.4 — experimental controls

This branch retains the current Niagara Drift visual language. The proposed
Volcano identity and larger redesign are reserved for v1.5.

## Navigation

- **SELECT encoder**: move backward/forward through pages belonging to the
  **current panel button**. The SEQ button's pages form a five-page cycle,
  including Transitions. SELECT does not leave SEQ for Swell.
- **Hold SEL and turn SELECT**: edit the existing LFO cycle/rate.
- The labeled panel buttons still jump to their corresponding page families.

## Scene browser

Tap **SAVE** to open the scene browser. Its four encoders have one job each:

| Encoder | Browser control |
|---|---|
| K1 | Bank (A, B, C, D, E, F, Presets 1–8, Presets 9–16) |
| K2 | Slot (1–8) |
| K3 | Action: **SAVE**, **LOAD**, **TRANSITION** |
| K4 | Transition's terminal morph percentage, 0–100% |

Press **SAVE** to confirm the action, or **HOME** to go back. SEL has no
function in the browser. **REC** opens a popup to rename the selected
**user scene slot** (K1 bank, K2 slot); it does not rename an entire bank.
In the naming popup, K1 selects the character, K2 changes the character
(A–Z, 0–9, space, hyphen), SAVE confirms and HOME cancels. Each of the
48 user scene slots can have its own name (up to eleven characters).
Factory Preset names are immutable. User slot names survive reboot.

SAVE stores the current sound in the selected bank/slot. When the user
slot is **empty**, the write proceeds immediately. If the slot already
contains a sound, an **OVERWRITE?** confirmation shows its bank, slot and
name: press **SAVE** again for Yes or **HOME** for Back. HOME returns to the
browser without changing or writing the scene. All encoders are ignored
until the question is answered. The existing slot remains untouched until
the second SAVE is released. **On the Volcano branch, LOAD immediately applies
the selected bank/slot**, including its authored sequence, without using Scene
Time; this is intended for project selection before playing. It keeps global
room settings and Pitch Lock but replaces the stored sound pitches. The v1.4
implementation previously used Scene Time for LOAD. Both factory Preset banks
can be loaded or targeted; attempts to SAVE over a factory Preset are refused
without offering an overwrite confirmation.

TRANSITION works from the currently sounding parameters toward the selected
bank/slot at the requested percentage. For example, at 40%, the final sound
is 40% of the way from the starting sound to the target; at 100%, the target
sound is reached. The existing Scene Time sets how long it takes to approach
that final amount. Continuous parameters interpolate, discrete switches
change at the halfway point, and the existing Pitch Lock and room-setting
exclusions remain in effect. Adjusting the browser values does not change
the sound until SAVE is pressed. A new transition starts from the **current**
sound rather than a previous source snapshot.

The project (including individual user scene-slot names) uses the existing
storage object. A new trailing slot-name array follows the previous v1.4
bank-name field, preserving existing format-45 scene offsets and allowing
older projects to load with unnamed slots. Existing experimental bank labels
are retained in storage for binary compatibility but are no longer edited or
shown. Slot names may be lost on downgrade to firmware that does not
understand them.

## Sequencer

SEQ page 5 controls the transition **shape** across each consecutive pair of
active nodes. K1 through K4 correspond to segments 1→2, 2→3, 3→4, and 4→1.
At the extremes, the value becomes a late or early instantaneous jump; the
middle is a sinusoidal ease. The display draws two-pixel-thick connected
curves (to survive scaling in the web emulator), including the full low
plateau and vertical jump of a late transition, and vertical edges at
the early transition. Audio interpolation is unchanged. Inactive segments
remain disabled.

## LFO

The existing filter modulation destination key cycles through Cutoff,
Resonance and Pan. Pan uses equal-power stereo gains and the existing LFO
routing, depth and Movement controls.

## Status

Experimental. Host and web-emulator tests must be run after each revision
before building or installing on the physical instrument. White keys 1–8 are deliberately unassigned on ordinary pages; scene
loading and saving now happens in the SAVE browser. They remain musical note
inputs on the SEQ note-entry page. Gesture keys 9–16 retain their existing
functions, without the former SEL+gesture bank shortcuts. Older host recipes
which explicitly request `legacykeys` exercise the retired scene-key
pressure/morph behavior for regression purposes; this flag is not accessible
in the normal firmware or web emulator.
