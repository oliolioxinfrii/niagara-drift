# Niagara Drift v1.4 — experimental controls

This branch retains the current Niagara Drift visual language. The proposed
Volcano identity and larger redesign are reserved for v1.5.

## Navigation

- **SELECT encoder**: move backward/forward through pages belonging to the
  **current panel button**. The SEQ button's pages form a five-page cycle,
  including Transitions. SELECT does not leave SEQ for Swell.
- **Hold SEL and turn SELECT**: edit the existing LFO cycle/rate.
- The labeled panel buttons still jump to their corresponding page families.

## Scene browser

Tap **SAVE** to open the scene browser. Its four encoders have one job each:

| Encoder | Browser control |
|---|---|
| K1 | Bank (A, B, C, D, E, F, Presets 1–8, Presets 9–16) |
| K2 | Slot (1–8) |
| K3 | Action: **SAVE**, **LOAD**, **TRANSITION** |
| K4 | Transition's terminal morph percentage, 0–100% |

Press **SAVE** to confirm the action, or **HOME** to go back. SEL has no
function in the browser. **REC** opens a popup to rename a user bank; it cannot
rename or overwrite either factory Preset bank. In the naming popup, K1 selects
the character, K2 changes the character (A–Z, 0–9, space, hyphen), SAVE confirms
and HOME cancels. Names are up to eleven characters and survive reboot.

SAVE stores the current sound in the selected bank/slot. LOAD recalls the
selected bank/slot using the existing Scene Time. Both Preset banks can be
loaded; attempts to SAVE over a factory Preset are refused.

TRANSITION works from the currently sounding parameters toward the selected
bank/slot at the requested percentage. For example, at 40%, the final sound
is 40% of the way from the starting sound to the target; at 100%, the target
sound is reached. The existing Scene Time sets how long it takes to approach
that final amount. Continuous parameters interpolate, discrete switches
change at the halfway point, and the existing Pitch Lock and room-setting
exclusions remain in effect. Adjusting the browser values does not change
the sound until SAVE is pressed. A new transition starts from the **current**
sound rather than a previous source snapshot.

The project (including user bank names) uses the existing storage object; the
name fields are appended to the existing format-45 structure so older projects
load without moving their stored scene data. These names may be lost on
downgrading to a build that does not understand them.

## Sequencer

SEQ page 5 controls the transition **shape** across each consecutive pair of
active nodes. K1 through K4 correspond to segments 1→2, 2→3, 3→4, and 4→1.
At the extremes, the value becomes a late or early instantaneous jump; the
middle is a sinusoidal ease. The display now draws connected single-pixel
curves and vertical edges at the saw endpoints. Inactive segments remain
disabled.

## LFO

The existing filter modulation destination key cycles through Cutoff,
Resonance and Pan. Pan uses equal-power stereo gains and the existing LFO
routing, depth and Movement controls.

## Status

Experimental. Host and web-emulator tests must be run after each revision
before building or installing on the physical instrument. The eight former
bank-selection shortcuts have not been reassigned to new functions. The
existing scene-trigger keys and gesture controls are otherwise unchanged
pending a separate keyboard-mapping review.
